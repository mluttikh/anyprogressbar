# How-to guides

Recipes for a task. Each stands on its own; they assume you know the basics from
[the tutorials](../tutorials/index.md).

- [Install anyprogressbar](install.md), with or without the notebook widget.
- [Totals, units and positions](totals.md): work of unknown size, totals that change, work
  that reports where it is.
- [Show values beside the bar](values.md): a loss, a file name, a count of errors.
- [Bars inside bars, and threads](nested.md): children, `weight=`, and work in other threads.
- [Failures, interruptions and skipped work](endings.md): how a bar ends, and how to end it
  yourself.
- [Print and log while bars run](print.md).
- [Choose where bars show](where.md): a terminal, a log, nothing; for one bar or all.
- [Bars in Jupyter, VS Code and marimo](notebooks.md), and what to do when a bar does not
  move.
- [Write a renderer of your own](renderer.md): send progress to a status page, a chat, a
  file.
- [Switch from tqdm](tqdm.md).
